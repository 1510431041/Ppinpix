# Ppinpix 键盘鼠标交互映射表（v1.0）

> 本文档完整列出 Ppinpix 所有键盘快捷键与鼠标交互。优先级标注：**P0** 必须实现、**P1** 应该实现、**P2** 可选实现。

---

## 1. 全局热键（任意窗口下生效）

| 热键 | 功能 | 默认 | 可自定义 | 优先级 | 里程碑 |
|------|------|------|----------|--------|--------|
| 截图 | 冻结屏幕进入截图模式 | `F1` | ✅ | P0 | M1 |
| 贴剪贴板 | 将剪贴板内容钉到屏幕 | `F3` | ✅ | P0 | M2 |
| 截图 OCR | 截图后立即识别文字 | `Ctrl+Shift+O` | ✅ | P1 | M3 |
| 截图翻译 | 截图后立即翻译 | `Ctrl+Shift+T` | ✅ | P1 | M4 |
| 显示/隐藏所有贴图 | 切换所有贴图可见性 | `Ctrl+Shift+H` | ✅ | P2 | M2 |

**说明**：
- 热键在设置中可自由配置
- 支持修饰键：`Ctrl` / `Shift` / `Alt` / `Win`（可任意组合）
- 支持按键：字母 A-Z、数字 0-9、F1-F12、方向键
- 冲突检测：已被系统或其他程序占用时显示警告
- 注册失败时托盘气泡提示

## 9. 特殊交互规则

### 9.1 多显示器行为
- 所有热键触发时在**当前鼠标所在显示器**操作
- 跨屏拖动选区/贴图时自动适配目标屏 DPI
- 放大镜、工具栏始终完整显示在鼠标所在屏内

### 9.2 边缘智能避让
- 放大镜靠近屏幕边缘时翻转到对侧（上→下，右→左）
- 工具栏优先选区下方，空间不足时自动放上方或选区内
- Toast 始终在工作区内（距边 16px）

### 9.3 冲突优先级
1. **覆盖层键盘输入 > 全局热键**（覆盖层显示时，`Esc` 先取消选区，再次 `Esc` 才退出）
2. **贴图焦点 > 全局热键**（贴图获得焦点时，`Esc` 关闭贴图而非触发全局热键）
3. **设置窗口 > 全局热键**（设置窗口打开时，全局热键不响应，避免误操作）

### 9.4 快捷键约定
- **单键快捷键**（A-Z、F1-F12）仅在覆盖层/工具栏/贴图等焦点窗口生效
- **组合键**（Ctrl/Shift/Alt）可作为全局热键
- 尽量遵循 Windows 通用约定：`Ctrl+C` 复制、`Ctrl+S` 保存、`Ctrl+Z` 撤销、`Esc` 取消
