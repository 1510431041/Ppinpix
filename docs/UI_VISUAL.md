# Ppinpix 界面视觉规范（v1.0）

> 本文档是 Ppinpix 所有界面的唯一视觉依据。新增或修改界面时必须遵循；如需偏离，先修改本文档再改代码。
> 代码中的颜色、尺寸、圆角、动效常量统一定义在 `src/Ppinpix.App/Theme/Tokens.cs` 与 `Theme/Theme.xaml`，**禁止在控件里硬编码数值**。

---

## 1. 设计理念

| 关键词 | 含义 |
|---|---|
| **克制** | 截图时屏幕内容才是主角。工具界面小、暗、贴边，不抢视线 |
| **精确** | 1 物理像素的线条在任何缩放下都是 1 物理像素；坐标、尺寸、色值永远可见可复制 |
| **即时** | 无加载动画、无多余过渡；动效只用于传达状态变化，且 ≤ 160ms |
| **一致** | 截图覆盖层、贴图、浮窗、设置页共用同一套色彩、圆角、图标与字体 |

整体风格：**Windows 11 Fluent 的深色浮层风格**——深灰半透明面板、细描边、柔和阴影、单一品牌强调色。

## 3. 字体

| 用途 | 字体 | 字号 / 字重 |
|---|---|---|
| 界面中文 | `Microsoft YaHei UI` | — |
| 界面西文 | `Segoe UI Variable`，回退 `Segoe UI` | — |
| 数字/坐标/色值 | `Cascadia Mono`，回退 `Consolas` | 12 / Regular，等宽便于对齐 |
| 图标 | `Segoe Fluent Icons`，回退 `Segoe MDL2 Assets` | 16 |

FontFamily 写作：`Segoe UI Variable, Segoe UI, Microsoft YaHei UI`。

| 层级 Token | 字号 | 字重 | 行高 |
|---|---|---|---|
| `Title` | 20 | SemiBold | 28 |
| `Subtitle` | 15 | SemiBold | 22 |
| `Body` | 13 | Regular | 20 |
| `Caption` | 12 | Regular | 16 |
| `Badge` | 11 | SemiBold | 14 |

所有字号均为 DIP，由系统按显示器缩放自动换算。

## 4. 尺寸、间距、圆角、阴影

- **间距基准 4 DIP**：可用值 `4 / 8 / 12 / 16 / 24 / 32`。
- **圆角**：浮层面板 `8`，按钮/输入框 `6`，小徽标 `4`，选区与标注框 `0`（截图是精确工具，选区永远直角）。
- **描边**：面板 1px `Stroke`。
- **阴影**：浮层 `0 8 24 rgba(0,0,0,.35)`；贴图 `0 4 16 rgba(0,0,0,.30)`；设置卡片无阴影。
- **控件高度**：按钮 / 输入框 `32`，工具栏按钮 `32×32`，列表项 `36`，设置导航项 `40`。
- **最小点击区域** `32×32`。

---

## 5. 图标

- 统一使用 **Segoe Fluent Icons**（Win11 自带，Win10 回退 MDL2），线性风格、16 DIP、颜色 `TextPrimary`；选中时 `Accent`。
- 字符映射集中于 `Theme/Icons.cs`，界面中只引用常量名。
- 托盘图标：16/20/24/32 多尺寸 `.ico`，蓝色圆角方形 + 白色取景框标志；暂停热键时显示灰色版本。

## 6. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 浮层出现（工具栏、菜单、浮窗） | 120ms，透明度 0→1 + 上移 4 DIP | `CubicEase Out` |
| 浮层消失 | 80ms，透明度 1→0 | Linear |
| 按钮悬停色变化 | 80ms | Linear |
| Toast | 出现 160ms，停留 1.6s，消失 160ms | `CubicEase Out` |
| **截图覆盖层出现** | **0ms，无动画**（必须瞬时，保证冻结画面准确） | — |
| 选区拖动、放大镜跟随 | 无缓动，逐帧跟手 | — |

系统设置“显示动画”关闭时所有动效时长取 0。

## 7. 组件规范

### 7.1 截图覆盖层

```
 ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  ← Dim 遮罩
 ░░░  ┌ 1280 × 720 ┐  ← 尺寸徽标：Surface 底，Caption，等宽数字，
 ░░░  ●─────────●─────────●        贴选区左上角外侧，空间不够时移入内侧
 ░░░  │                   │
 ░░░  ●     （原始亮度）    ●  ← 选区内不加遮罩，1px Accent 边框
 ░░░  │                   │
 ░░░  ●─────────●─────────●
 ░░░            ┌──────────────────────────────────┐
 ░░░            │ ▢ ○ ↗ ╱ ✎ ① T ▦ ▤ │ ↶ ↷ │ 📌 ⎘ 💾 ✕ ✓ │  ← 工具栏
 ░░░            └──────────────────────────────────┘
```

- **工具栏**：`Surface` 背景、8 圆角、1px 描边、阴影；高 40，按钮 32×32，间距 4，组间 1px×20 分隔线。
- **位置**：默认在选区**右下角外侧下方 8 DIP**、右对齐；下方空间不足 → 放选区上方；都不够 → 放选区内右下角。始终完整处于鼠标所在显示器内。
- 按钮顺序：`矩形 椭圆 箭头 直线 画笔 序号 文字 马赛克 荧光笔 | 撤销 重做 | 贴图 OCR 翻译 | 保存 复制 取消 完成`。（OCR/翻译在第 3、4 阶段启用前隐藏。）
- **完成 ✓** 使用 `Accent` 填充按钮，其余为透明按钮。
- **工具属性条**：选中标注工具后在工具栏下方 4 DIP 处弹出二级条，含线宽（3 档圆点）、8 色色块（18×18 圆形，选中外加 2px 白环）、字号等。
- **悬停提示**：Tooltip 显示“名称  快捷键”，快捷键用 `TextSecondary`。

### 7.2 窗口/控件识别高亮

- 悬停未按下时：识别矩形外遮罩、内部原亮度，2px `Accent` 边框 + 10% 填充；左上角徽标显示 `宽 × 高`。
- 层级切换（滚轮）时边框瞬时切换，无动画。

### 7.3 放大镜

```
┌───────────────────────┐
│ ┌───────────────────┐ │  放大区 120×120 DIP，15×15 像素 ×8
│ │  像素网格 + 十字    │ │  网格线 #FFFFFF @ 12%
│ │       ┼            │ │  中心像素：1px 白框 + 1px 黑框（任何底色可见）
│ └───────────────────┘ │
│ ■ #2F80FF   (1920,540) │  色块 12×12 + HEX + 坐标，等宽字体
│ C 复制颜色  Shift 切换  │  Caption / TextSecondary
└───────────────────────┘
```

- `Surface` 背景、8 圆角；位于光标右下 20 DIP，靠近屏幕边缘时翻转到左/上。
- 正在拖动选区或绘制标注时隐藏（可设置）。

### 7.4 标注默认样式

| 工具 | 默认 |
|---|---|
| 矩形/椭圆 | 线宽 3（档位 2/3/5），红色，无填充 |
| 箭头 | 线宽 3，实心三角箭头，箭头长度 = 线宽×4 |
| 序号 | 直径 24 实心圆（档位 20/24/32），白色 SemiBold 数字，起始 1 |
| 文字 | 18 SemiBold，红色，可开 2px 白色描边 |
| 马赛克 | 块大小 12 物理像素；模糊半径 12 |
| 选中态 | 虚线包围框 1px `Accent` + 白色手柄 |

### 7.5 贴图窗口

- 内容四周 1px `Stroke` 描边（激活时变 1px `Accent`），外加贴图阴影；无标题栏。
- 缩放/透明度变化时在中心显示 `Surface` 徽标 “150%” / “透明度 70%”，停留 800ms 后淡出。
- **折叠态**：高 28 的胶囊条，宽 160，显示缩略图 20×20 + “贴图 3”。
- **穿透态**：右上角显示 14×14 的穿透图标徽标（`Surface` 底）。
- 右键菜单使用 7.7 规范。

### 7.6 Toast

- 屏幕右下角（鼠标所在显示器工作区内，距边 16），`Surface` 背景，左侧 3px 语义色竖条，图标 + 一行 `Body` 文字，最大宽 320。
- 例：“已复制到剪贴板”（Success）、“F1 已被其他程序占用”（Warning）。

### 7.7 右键菜单 / 托盘菜单

- `Surface` 背景、8 圆角、内边距 4；菜单项高 32、左右内边距 12、图标 16 + 间距 12；快捷键右对齐 `TextSecondary`；分隔线 1px `Stroke`，上下各 4。
- 托盘菜单项：`截图  F1` · `贴图剪贴板  F3` · `显示/隐藏所有贴图` · 分隔 · `暂停热键` · `设置…` · 分隔 · `退出`。

### 7.8 翻译对照浮窗（第 4 阶段）

- 宽 420（可拖拽 320–720），`Surface` 背景，8 圆角。
- 标题栏 36：配置名下拉、语言 `自动 → 中文` 下拉、钉住、关闭。
- 原文区 `SurfaceRaised` 底，可编辑；译文区无底色，正文 `Body` 14/22；流式输出时末尾 `Accent` 闪烁光标 `▍`（530ms 周期）。
- 底栏：`复制译文`(主按钮) `复制原文` `复制双语`，右侧 `停止` 与耗时 `Caption`。

## 8. 高分屏规则

1. 所有尺寸以 DIP 定义，按**所在显示器**的缩放换算；跨屏移动时立刻重排。
2. 以下元素必须是**1 物理像素**，不随缩放变粗：选区边框、放大镜网格线、尺寸测量线。
3. 图标使用字体图标或矢量，**禁止位图图标**（托盘 `.ico` 除外，需提供多尺寸）。
4. 截图内容按 1:1 物理像素显示，禁止插值缩放；贴图缩放时 ≥100% 用最近邻（像素清晰），<100% 用高质量双三次。
5. 验收：100% / 125% / 150% / 200% 及混合双屏下逐项截图比对。

## 9. 文案

- 中文界面，简短、动词开头：“复制”“保存”“贴到屏幕”。不用“您”，不用感叹号。
- 快捷键写法：`Ctrl+Shift+T`；尺寸写法：`1280 × 720`（× 两侧空格）。
- 错误提示 = 发生了什么 + 怎么办：“连接超时。请检查接口地址或代理设置。”
