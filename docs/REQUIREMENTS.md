# Ppinpix 产品需求文档（PRD v1.0）

## 1. 产品定位

**Ppinpix** 是一款对标 PixPin 的内部免费 Windows 桌面截图与翻译工具，为内部用户提供：
- **智能截图与标注**：全局热键截图、窗口/控件自动识别、像素级放大取色、丰富标注工具
- **悬浮贴图**：截图/剪贴板内容钉在屏幕上，缩放/透明/折叠/鼠标穿透
- **纯本地离线 OCR**：截图/贴图文字识别、二维码扫描，完全离线
- **自定义大模型翻译**：支持任意 OpenAI 兼容接口，截图翻译对照或原位覆盖

**核心价值**：
1. **完美 DPI 支持**：混合缩放多屏环境下像素级精准
2. **隐私保证**：除翻译请求外零外联，所有数据本地处理
3. **灵活集成**：支持公司内部大模型网关或任意兼容接口
4. **完全免费**：内部使用，无订阅/无限制

---

## 2. 目标用户

- **主要用户**：技术团队（开发、测试、产品、设计），需要频繁截图标注、技术文档翻译
- **使用场景**：
  - 截图标注后发到工作群/文档/JIRA
  - 英文技术文档/界面截图翻译
  - 代码错误信息/日志截图 OCR 后搜索
  - 会议/演示时固定参考图片在屏幕角落
- **使用环境**：Windows 10 (1809+) / Windows 11，常见高分屏（150% / 200%）+ 外接显示器混合 DPI

## 3. 功能需求

### 3.1 模块一：智能截图与标注

#### 3.1.1 截图触发
- **FR-1.1** 全局热键触发（默认 `F1`），立即冻结屏幕并进入选区模式
- **FR-1.2** 托盘菜单「截图」选项
- **FR-1.3** 支持延迟截图（1/2/3/5 秒倒计时）
- **FR-1.4** 可选是否捕获鼠标指针
- **FR-1.5** 支持多显示器（所有屏幕同时冻结，自由跨屏选区）

#### 3.1.2 窗口/控件智能识别
- **FR-1.6** 鼠标悬停时自动识别窗口边界，高亮显示（2px 蓝色边框 + 10% 填充）
- **FR-1.7** 识别子窗口、按钮、输入框等控件（基于 UI Automation）
- **FR-1.8** 滚轮或 `Tab` 键在窗口/子窗口/控件三层级之间切换
- **FR-1.9** 单击确认当前高亮区域为选区
- **FR-1.10** 手动拖拽矩形选区时自动吸附窗口/控件边缘（距离 < 8px）
- **FR-1.11** 按住 `Alt` 临时关闭吸附

#### 3.1.3 选区调整
- **FR-1.12** 拖拽 8 个手柄（四角+四边中点）调整选区
- **FR-1.13** 拖拽选区内部移动整个选区
- **FR-1.14** 方向键微调位置（1px），`Shift+方向键` 微调尺寸（1px）
- **FR-1.15** 选区左上角显示尺寸徽标「宽 × 高」（像素单位）

#### 3.1.4 像素放大镜与取色
- **FR-1.16** 鼠标移动时跟随显示放大镜（15×15 像素 ×8 倍）
- **FR-1.17** 放大镜显示像素网格、中心十字、当前坐标
- **FR-1.18** 显示鼠标位置颜色（HEX 格式，如 `#2F80FF`）
- **FR-1.19** 显示当前光标坐标（物理像素）
- **FR-1.20** 按 `C` 复制当前颜色
- **FR-1.21** 按 `Shift` 切换颜色格式（HEX ↔ RGB）
- **FR-1.22** 放大镜自动避让屏幕边缘（翻转到对侧）
- **FR-1.23** 拖动选区时隐藏放大镜（可在设置中关闭此行为）

#### 3.1.5 标注工具（M2 实现）
- **FR-1.24** 矩形：可设线宽（2/3/5px）、颜色、实心/空心
- **FR-1.25** 椭圆：参数同矩形
- **FR-1.26** 箭头：可设线宽、颜色，实心三角箭头
- **FR-1.27** 直线：可设线宽、颜色、实线/虚线
- **FR-1.28** 画笔：自由绘制，可设粗细、颜色
- **FR-1.29** 递增序号：圆形徽标 ①②③，可设大小（20/24/32px）、颜色、起始数字
- **FR-1.30** 文字：多行输入，可设字号、颜色、加粗、描边
- **FR-1.31** 马赛克：矩形区域打码，可设块大小
- **FR-1.32** 高斯模糊：矩形区域模糊
- **FR-1.33** 荧光笔：半透明高亮画笔
- **FR-1.34** 橡皮擦：擦除标注（不影响原图）
- **FR-1.35** 8 色调色板（红/橙/黄/绿/蓝/紫/白/黑），工具栏一键切换
- **FR-1.36** 标注对象可二次选中、移动、删除、修改样式
- **FR-1.37** 撤销（`Ctrl+Z`）、重做（`Ctrl+Y`），无次数限制

#### 3.1.6 工具栏与快捷键
- **FR-1.38** 确认选区后显示浮动工具栏（深色半透明面板）
- **FR-1.39** 工具栏按钮：矩形/椭圆/箭头/直线/画笔/序号/文字/马赛克/荧光笔 | 撤销/重做 | 贴图/OCR/翻译 | 保存/复制/取消/完成
- **FR-1.40** 工具栏智能定位：优先选区下方，空间不足时放上方或内部
- **FR-1.41** 完成按钮使用品牌色强调（蓝色填充）
- **FR-1.42** 鼠标悬停按钮时显示提示（名称 + 快捷键）
- **FR-1.43** 快捷键：`Enter` 完成并复制、`Ctrl+S` 保存、`Ctrl+T` 贴图、`Esc` 取消

#### 3.1.7 输出
- **FR-1.44** 复制到剪贴板（PNG 格式）
- **FR-1.45** 保存为文件（PNG/JPG，M3 增加 WebP）
- **FR-1.46** 文件名支持模板：`Screenshot_{yyyy-MM-dd}_{HH-mm-ss}.png`
- **FR-1.47** 可配置默认保存路径
- **FR-1.48** 保存/复制成功后显示 Toast 提示

### 3.2 模块二：悬浮贴图（Pin）

#### 3.2.1 创建贴图

  - 文件路径 → 若为图片则加载显示
- **FR-2.3** 贴图窗口默认在截图位置显示，始终置顶

#### 3.2.2 贴图操作
- **FR-2.4** 左键拖动移动贴图
- **FR-2.5** 滚轮缩放（10%~1000%，以光标为中心）
- **FR-2.6** `Ctrl+滚轮` 调整不透明度（10%~100%）

- **FR-2.8** 缩放/透明度变化时中心显示徽标（如「150%」「透明度 70%」），800ms 后淡出
- **FR-2.9** 双击标题区折叠为缩略条（显示缩略图 + "贴图 3"）
- **FR-2.10** 再次双击展开
- **FR-2.11** 按 `H` 隐藏贴图（托盘菜单「显示所有贴图」恢复）

#### 3.2.3 鼠标穿透
- **FR-2.13** 右键菜单「鼠标穿透」切换穿透状态
- **FR-2.14** 穿透时右上角显示穿透图标徽标
- **FR-2.15** 穿透时贴图不响应鼠标操作，点击会穿透到下层窗口
- **FR-2.16** 按住 `Ctrl+Alt` 临时解除穿透（松开恢复）
- **FR-2.17** 全局热键或托盘菜单可恢复穿透贴图的交互

#### 3.2.4 贴图菜单
- **FR-2.18** 右键显示菜单：复制/保存/编辑标注/OCR/翻译/旋转/翻转/置顶开关/鼠标穿透/关闭
- **FR-2.19** 「复制」复制当前贴图（含标注、缩放后的效果）
- **FR-2.20** 「保存」保存为文件
- **FR-2.21** 「编辑标注」重新进入标注模式（M2）
- **FR-2.22** 「OCR」识别文字（M3）
- **FR-2.23** 「翻译」发送给大模型翻译（M4）
- **FR-2.24** 「置顶开关」控制是否始终最前

#### 3.2.5 贴图上文字划选（M3）
- **FR-2.25** 创建贴图后自动静默 OCR（可在设置中关闭）
- **FR-2.26** 鼠标移到文字区域时光标变为 I 型
- **FR-2.27** 拖拽按阅读顺序选中文字，高亮显示
- **FR-2.28** `Ctrl+C` 或右键「复制选中文字」
- **FR-2.29** `Ctrl+A` 全选所有文字
- **FR-2.30** 按住 `Space` 拖动贴图（避免与文字选择冲突）

#### 3.2.6 贴图管理
- **FR-2.31** 托盘菜单「显示/隐藏所有贴图」一键切换
- **FR-2.32** 支持同时存在多个贴图（无数量限制）
- **FR-2.33** 可选「退出时保存贴图，下次启动恢复」（默认关闭）

### 3.3 模块三：离线 OCR（M3）

#### 3.3.1 OCR 触发
- **FR-3.1** 截图工具栏「OCR」按钮
- **FR-3.2** 贴图右键「OCR」
- **FR-3.3** 独立全局热键（默认 `Ctrl+Shift+O`）截图并 OCR

#### 3.3.2 文字识别
- **FR-3.4** 使用本地 RapidOCR 引擎（PP-OCRv4 ONNX），完全离线
- **FR-3.5** 支持中英文混合（默认模型）
- **FR-3.6** 可选日语/韩语/繁体语言包（独立模型文件）
- **FR-3.7** 返回文字内容、位置框、置信度
- **FR-3.8** 自动段落重组（按行高、行距、对齐聚类）
- **FR-3.9** 1080p 截图识别时间 < 500ms（目标）

#### 3.3.3 二维码/条码识别
- **FR-3.10** 同时扫描二维码、条码（使用 ZXing.Net）
- **FR-3.11** 返回内容、类型、位置

#### 3.3.4 OCR 结果面板
- **FR-3.12** 弹出结果窗口显示识别文字（可编辑）
- **FR-3.13** 「复制全部」按钮
- **FR-3.14** 「翻译」按钮（跳转翻译功能）
- **FR-3.15** 二维码内容单独显示（链接不自动打开，仅显示）
- **FR-3.16** 显示识别耗时

#### 3.3.5 性能与资源
- **FR-3.17** OCR 模型懒加载（首次使用时加载）
- **FR-3.18** 模型常驻内存，空闲 5 分钟后可选释放
- **FR-3.19** 独立工作线程处理，不阻塞 UI
- **FR-3.20** 大图自动缩放（长边 1600px）优化性能

### 3.4 模块四：大模型翻译（M4）

#### 3.4.1 翻译触发
- **FR-4.1** 截图工具栏「翻译」按钮
- **FR-4.2** 贴图右键「翻译」
- **FR-4.3** OCR 结果面板「翻译」按钮
- **FR-4.4** 独立全局热键（默认 `Ctrl+Shift+T`）截图并翻译
- **FR-4.5** 首次使用翻译时提示「截图内容将发送至：<URL>」，可勾选不再提示

#### 3.4.2 翻译模式
- **FR-4.6** 模式一：先本地 OCR 再翻译（默认）
  - 本地识别文字 → 发送纯文本给模型
  - 适用于纯文本模型，省 token，速度快
- **FR-4.7** 模式二：直接发图翻译
  - 将截图（PNG/JPEG，长边≤2048）发给多模态模型
  - 适用于复杂排版、手写、艺术字
- **FR-4.8** 每套 API 配置可单独设定默认模式

#### 3.4.3 语言识别与方向
- **FR-4.9** 自动互译（默认）：中文 → 英文，其它 → 中文
- **FR-4.10** 工具条可手动选择源语言/目标语言
- **FR-4.11** 支持语言：中/英/日/韩/法/德/西/俄等（可配置列表）
- **FR-4.12** 记住上次选择

#### 3.4.4 呈现方式 A：对照浮窗
- **FR-4.13** 默认呈现方式，弹出浮动对照窗口
- **FR-4.14** 窗口宽 420px（可拖拽调整 320~720px）
- **FR-4.15** 上半部显示原文（可编辑）
- **FR-4.16** 下半部显示译文（流式输出，只读）
- **FR-4.17** 流式输出时末尾显示闪烁光标 `▍`（530ms 周期）
- **FR-4.18** 标题栏显示：配置名下拉/语言方向下拉/钉住/关闭
- **FR-4.19** 修改原文后 `Ctrl+Enter` 重新翻译
- **FR-4.20** 切换配置/模型后可重新翻译（便于对比）
- **FR-4.21** 底栏按钮：复制译文/复制原文/复制双语/停止
- **FR-4.22** 显示翻译耗时
- **FR-4.23** 可钉住窗口（保持置顶）

#### 3.4.5 呈现方式 B：原位覆盖（M4 后期）
- **FR-4.24** 可选呈现方式，在原图上覆盖译文
- **FR-4.25** 本地 OCR 获取段落位置框
- **FR-4.26** 要求模型返回结构化 JSON（段落 id + 译文）
- **FR-4.27** 流式解析，每完成一段立刻覆盖一段
- **FR-4.28** 自动适配背景色（取段落外沿像素中位数）
- **FR-4.29** 自动适配文字颜色（取框内像素聚类，选高对比度）
- **FR-4.30** 自动适配字号（二分搜索最大可放入字号）
- **FR-4.31** 结果以新贴图形式呈现
- **FR-4.32** 按住 `Alt` 或点按钮临时显示原图对比
- **FR-4.33** 可复制/保存覆盖后的图片

#### 3.4.6 停止与错误处理
- **FR-4.34** 翻译进行中可随时「停止」（取消请求）
- **FR-4.35** 网络错误/超时显示友好提示（分类：连接失败/认证失败/限流/超时）
- **FR-4.36** 模型返回 JSON 格式错误时自动回退到对照浮窗模式
- **FR-4.37** 日志中自动脱敏 API Key

### 3.5 大模型 API 配置

#### 3.5.1 配置管理
- **FR-5.1** 支持添加多套 API 配置
- **FR-5.2** 标记一套为「当前默认」
- **FR-5.3** 翻译时可临时切换配置
- **FR-5.4** 配置列表显示：名称/接口地址/模型名/默认标记
- **FR-5.5** 支持复制/编辑/删除配置

#### 3.5.2 配置项
- **FR-5.6** 配置名称（如「公司网关-GPT4o」）
- **FR-5.7** 协议类型：OpenAI 兼容（默认）/ Anthropic / Gemini
- **FR-5.8** 接口地址（如 `https://api.2020111.xyz/v1`）
- **FR-5.9** 默认配置预填：`https://api.2020111.xyz/v1` + 模型 `翻译`
- **FR-5.10** API Key（密码框，必填）
- **FR-5.11** 模型名称（文本输入 + 可选「获取模型列表」按钮）
- **FR-5.12** 翻译 Prompt（多行编辑器，支持变量：`{source_lang}` `{target_lang}` `{text}`）
- **FR-5.13** 「恢复默认 Prompt」按钮
- **FR-5.14** 识别模式选择：OCR 后翻译 / 直接发图
- **FR-5.15** 网络代理：不使用 / 跟随系统 / HTTP / SOCKS5
- **FR-5.16** 高级选项：温度/最大 tokens/超时/是否流式/额外 Header

#### 3.5.3 安全性
- **FR-5.17** API Key 使用 DPAPI 加密存储（CurrentUser 作用域）
- **FR-5.18** 加密盐（entropy）随机生成并单独存储
- **FR-5.19** UI 不回显明文 Key（密码框显示 ••••）
- **FR-5.20** 「显示」按钮需二次确认才临时显示明文
- **FR-5.21** 内存中仅在发送请求时解密，使用后立即清零
- **FR-5.22** 导出配置时默认不含 Key（可选勾选包含）
- **FR-5.23** 日志/错误信息中自动脱敏 `Authorization` / `x-api-key`

#### 3.5.4 测试连接
- **FR-5.24** 「测试连接」按钮发送最小请求验证配置
- **FR-5.25** 成功时显示：✅ + 耗时 + 模型返回内容
- **FR-5.26** 失败时显示分类提示：
  - DNS 错误/连不上 → 检查 URL/代理
  - TLS 错误 → 证书问题
  - 401/403 → API Key 无效
  - 404 → URL 或模型名错误
  - 429 → 限流/余额不足
  - 超时 → 网络慢/接口慢
- **FR-5.27** 显示原始响应前 500 字符（Key 已脱敏）
- **FR-5.28** 自动探测是否支持流式（再发一次流式请求）

## 5. 约束与限制

### 5.1 平台约束
- **CON-1.1** M1 仅支持 Windows（WPF + Win32）
- **CON-1.2** 需要 .NET 10 Desktop Runtime（或自包含发布）
- **CON-1.3** 需要 Windows 10 1809+ 支持 PerMonitorV2

### 5.2 功能边界
- **CON-2.1** M1 不含标注工具（仅截图+放大镜+取色）
- **CON-2.2** M1-M2 不含 OCR
- **CON-2.3** M1-M3 不含翻译
- **CON-2.4** 不支持长截图（滚动截图）
- **CON-2.5** 不支持录屏/GIF 录制
- **CON-2.6** 不支持视频 OCR

### 5.3 技术约束
- **CON-3.1** UI Automation 在部分应用（Electron/游戏）可能失效，自动降级窗口级
- **CON-3.2** DRM 保护内容截图为黑屏（Windows 限制）
- **CON-3.3** 全屏独占游戏可能截不到（降级 BitBlt，仍可能黑屏）
- **CON-3.4** 某些杀软可能拦截键盘钩子（鼠标穿透功能）

### 5.4 隐私约束
- **CON-4.1** 翻译功能必须用户主动触发
- **CON-4.2** 翻译接口地址/Key 由用户自行配置
- **CON-4.3** 不得在用户不知情时上传任何数据

- 打开代码截图 → 拖入 Ppinpix → 贴图显示 → 右键「OCR」→ 复制识别的代码文本 → 粘贴到 Markdown
