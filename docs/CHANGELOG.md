## [1.0.0] - 2026-11-14

### 已完成里程碑汇总
- **M1 智能截图**：全局热键、多屏混合 DPI 捕获、窗口/子控件智能吸附、放大镜与取色、剪贴板与文件输出。
- **M2 悬浮贴图与标注**：9 种标注工具（含马赛克与高斯模糊）、无限撤销/重做、悬浮贴图（缩放/旋转/翻转/折叠/透明度/穿透/会话恢复）。
- **M3 离线 OCR 与条码**：RapidOCR + Windows OCR 双引擎、版面段落聚类、贴图静默 OCR 划词复制、ZXing 二维码/条码识别。
- **M4 大模型截图翻译**：
  - 默认采用**原位覆盖贴图**模式：截图翻译不弹独立窗口，直接在原图位置生成贴图并流式覆盖译文，支持按住 `Alt` 临时对比原图、右键快速切换目标语言重译及转入对照浮窗。
  - 支持 OpenAI 兼容、Anthropic Messages、Google Gemini 协议及 HTTP/SOCKS5 代理。
  - DPAPI 密钥加密、首次外发隐私确认弹窗、`UserInitiatedToken` 防后台调用及 `Ppinpix.ArchTests` 架构隔离验证。

## [0.1.0-M1] - 计划于 2025-11-30

### 新增
- ✅ 全局热键截图（默认 `F1`）
- ✅ 多显示器支持（混合 DPI、负坐标、热插拔）
- ✅ 窗口/控件智能识别（自动高亮、滚轮切换层级）
- ✅ 手动选区（拖拽矩形、自动吸附边缘）
- ✅ 选区调整（8 个手柄、方向键微调）
- ✅ 像素放大镜（15×15 @×8、像素网格、坐标显示）
- ✅ 颜色拾取（HEX/RGB、按 `C` 复制）
- ✅ 复制到剪贴板（PNG 格式）
- ✅ 保存为文件（PNG/JPG、可配置路径和文件名模板）
- ✅ 托盘图标与菜单
- ✅ 设置窗口（常规、快捷键、截图设置、关于）
- ✅ 单实例运行
- ✅ PerMonitorV2 DPI 完美支持

### 技术实现
- .NET 10 + C# 13 + WPF
- GDI BitBlt + CAPTUREBLT 截图
- EnumWindows + DwmGetWindowAttribute 窗口识别
- RegisterHotKey 全局热键
- DPAPI 加密存储（为 M4 API Key 做准备）
- 日志自动脱敏

### 性能指标
- 热键到覆盖层 < 150ms（双 4K 屏）
- 拖动选区 60fps
- 常驻内存 < 80MB

### 已知限制
- 无标注工具（M2 实现）
- 无贴图功能（M2 实现）
- 无 OCR 功能（M3 实现）
- 无翻译功能（M4 实现）

## 版本说明

### 版本号规则
- **主版本号（Major）**：不兼容的 API 变化
- **次版本号（Minor）**：向下兼容的功能新增
- **修订号（Patch）**：向下兼容的问题修复
- **里程碑标记（-M1/-M2/-M3/-M4）**：v0.1.0 开发阶段的里程碑

### 发布节奏
- **M1-M4**：每 2-4 周发布一个里程碑
- **v1.0 正式版**：M4 完成后，经过完整验收测试后发布
- **后续版本**：按季度发布（v1.1, v1.2, ...）

### 支持政策
- **v1.x**：长期支持，持续 Bug 修复和安全更新
- **v0.x**：开发版本，仅在开发期间维护
